03 / NLP pipeline

How it works

A lightweight, explainable text-processing workflow.

STEP 01

Text normalization

Convert the input sentence to lowercase so matching is case-insensitive.

STEP 02

Tokenization

Extract individual word tokens using a regular expression.

STEP 03

Stop-word removal

Remove common words such as “the”, “is”, “this” and “for”.

STEP 04

Sentiment scoring

Count positive and negative dictionary matches, then compare totals.

Project aim

To develop a simple Python-based sentiment analysis system that classifies user text into Positive, Negative, or Neutral categories.

Software requirements

  • Python 3
  • VS Code, IDLE, or another Python editor
  • Python standard libraries — no extra packages

Algorithm

  1. Read the user's sentence.
  2. Lowercase and tokenize the text.
  3. Remove common stop words.
  4. Count positive and negative words.
  5. Return the category with the higher count; ties are Neutral.

Known limitation: This beginner-level lexicon classifier may not understand sarcasm, context, negation (such as “not good”), or words missing from its dictionaries. It is an academic demonstration, not a production sentiment model.

Classification rule

Simplified view of the decision logic used by the Python program.

PYTHON LOGIC
if positive_count > negative_count:
    sentiment = "Positive"
elif negative_count > positive_count:
    sentiment = "Negative"
else:
    sentiment = "Neutral"

Conclusion

This mini project demonstrates basic NLP preprocessing and sentiment classification using Python. It provides an introduction to how computers can identify sentiment from text.

Future enhancement

The project report suggests using a larger labelled dataset, a machine-learning model such as Naive Bayes, and more advanced preprocessing to handle negation and context.
